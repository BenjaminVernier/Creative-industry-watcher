# 🛰️ Creative Industry Watcher

A free, self-updating dashboard of trending news across **music, VFX, and film & TV** —
sorted into categories that matter for the business: emerging artists, new studios, creative
tech, funding, and more.

- **Front-end:** static HTML/CSS/JS in `docs/` — no build step, no dependencies.
- **Data:** `docs/data/news.json`, regenerated by a scheduled Claude Code routine.
- **The "AI":** the routine itself summarizes and categorizes each item — **no API key, $0 in API costs.**
- **Hosting:** GitHub Pages (free). **Updating:** a scheduled cloud routine that commits new data.

```
Creative-industry-watcher/
├─ docs/                 ← GitHub Pages serves this folder
│  ├─ index.html
│  ├─ styles.css
│  ├─ app.js             ← UI + the category taxonomy (source of truth)
│  └─ data/news.json     ← regenerated each run
├─ feeds.json            ← curated RSS sources
├─ ROUTINE.md            ← the exact prompt the scheduled routine runs
└─ README.md
```

## Run it locally

```bash
cd docs && python3 -m http.server 8777
```

Then open http://localhost:8777.

## One-time setup

### 1. Put it on GitHub

```bash
gh repo create creative-industry-watcher --public --source=. --remote=origin --push
```

(or create an empty repo on github.com and `git remote add origin … && git push -u origin main`.)

### 2. Turn on GitHub Pages

Repo → **Settings → Pages** → *Build and deployment* → **Source: Deploy from a branch** →
Branch **main**, folder **/docs** → Save. Your site goes live at
`https://<your-username>.github.io/creative-industry-watcher/` within a minute or two.

### 3. Schedule the update routine

The routine runs the **Run prompt** in [`ROUTINE.md`](ROUTINE.md) against this repo on a schedule
(daily is a good default at low traffic). It fetches feeds, writes `docs/data/news.json`, and
pushes — Pages redeploys automatically. See ROUTINE.md for the exact instructions to register.

## Customizing

- **Categories:** edit the `CATEGORIES` array in [`docs/app.js`](docs/app.js). The routine reads
  the same list, so the UI and the data never drift.
- **Sources:** add or remove feeds in [`feeds.json`](feeds.json).
- **Look:** all colors and spacing are CSS variables at the top of [`docs/styles.css`](docs/styles.css).

## Notes on sources

Several major trade feeds (Variety, Deadline, The Hollywood Reporter, IndieWire — all PMC) sit
behind a "tollbit" paywall that blocks automated fetching, so the routine skips them and favors
open feeds (Music Business Worldwide, MusicTech, CG Channel, fxguide, Animation World Network,
TheWrap, …). Headlines always link back to the original publisher.
